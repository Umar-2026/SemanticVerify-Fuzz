package and complete the external editable review form.

- reviewer name;
- reviewer role;
- confirmation/signature;
- review date;
- independent-review attestation;
- ASER01-ASER09 decisions;
- reviewer notes for all nine review items;
- overall review decision;
- overall reviewer notes.

`PASS`

or

`REVISION_REQUIRED`
