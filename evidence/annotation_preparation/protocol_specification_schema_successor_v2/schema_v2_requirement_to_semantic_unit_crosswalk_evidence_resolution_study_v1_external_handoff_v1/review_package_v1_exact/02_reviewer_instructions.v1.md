# Independent Reviewer Instructions

This package is an immutable author-produced review package for the Requirement-to-Semantic-Unit Crosswalk Evidence Resolution Study V1.

The repository copy of the reviewer packet is intentionally blank.

No human review has yet been performed.

Review scope is exactly CWXR01 through CWXR08.

The reviewer must independently inspect the packaged evidence and enter one allowed decision for every review item:

- PASS
- REVISION_REQUIRED
- FAIL

The reviewer must also enter one overall decision:

- APPROVE_REQUIREMENT_TO_SEMANTIC_UNIT_CROSSWALK_EVIDENCE_RESOLUTION_STUDY_V1
- REVISION_REQUIRED
- FAIL

The reviewer must supply their own identity, confirmation/signature, review date, and notes.

The author must not pre-fill or synthesize any reviewer decision or identity.

Approval of the study, if independently supplied, accepts only the bounded technical result under review. It does not itself constitute governance adoption and does not authorize operational mapping, schema modification, analyzer execution, baseline execution, or repair.

External reviewer handoff is not authorized by this package-authoring decision and requires a separate governance step.
