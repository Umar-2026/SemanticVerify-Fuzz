# Schema V2 Activation Governance Package V1

This package is a review package only.

It does not activate Schema V2.

It does not modify Decision 0019.

It does not create the active Schema V2 hash/canonicalization contract at
`config/protocol_content_hash_canonicalization.v2.json`.

It does not define or authorize a positive V4-to-V2 mapping.

It does not create `config/protocol_specifications/curl.json`.

It does not authorize analyzer implementation/execution, baseline execution,
or repair.

The package exists to let an independent human reviewer evaluate AG01 through
AG09 before any later activation decision is permitted.
