## Purpose

This packet is for acquisition of **new positive semantic-binding evidence**.

The reviewer evaluates each of the 17 canonical requirements against the
complete governed 109-semantic-unit domain.

For each requirement, the reviewer may enter exactly one evidence state:

- `POSITIVE_BINDING_PROPOSED`
- `UNRESOLVED_NO_POSITIVE_BINDING_PROPOSED`

If `POSITIVE_BINDING_PROPOSED` is selected, enter one or more exact
`unit_id` values and provide an explicit semantic rationale.

`UNRESOLVED_NO_POSITIVE_BINDING_PROPOSED` means only that the reviewer is
not proposing positive evidence. It is **not** a negative binding conclusion.
